# SkillForge roadmap

SkillForge should remain a small deterministic tool. New rules need a real failure case, a stable contract source, positive and negative fixtures, and an actionable message.

## Near term

- Add rule-code and inline suppressions with an audit trail.
- Expand the golden corpus against current public extensions.
- Add structured markdown reports for pull-request comments.
- Validate image signatures and dimensions for plugin visual assets.
- Inspect executable permissions and local MCP command entry points across operating systems.

## Later

- Optional model-backed trigger evaluation as a separate command from static smoke.
- Contract adapters for additional agent ecosystems.
- Machine-readable contract version reporting.
- Baseline files for intentionally accepted advisories.

## Shipped in the current source

- Strict current-contract plugin and skill schemas.
- Full YAML frontmatter parsing.
- Source and marketplace profiles.
- JSON, text, and SARIF reports.
- Expected-skill static smoke cases.
- Deterministic allowlisted archives.
- Current plugin and skill scaffolds.
- Cross-platform CI, dependency auditing, formatting, and coverage gates.
